## 一、成片规格与交付版本

| 项目 | 建议值 |
| --- | --- |
| 分辨率 | 1920 × 1080（长边不低于 1600，避免录屏字迹发虚） |
| 帧率 | 30 fps（若后续做速度线包装可用 60 fps 录制再降到 30 输出） |

| 主版本时长 | 3 分 50 秒（完整版） |
| 备选版本 | 90 秒精编版、45 秒纯大屏版（用于不同场合循环播放） |
| 旁白 | 中文普通话男声，语速约 230 字/分钟；也可只做字幕 + BGM |

**三个版本的取舍**

- **3 分 50 秒完整版**：九个段落全部保留，硬件、链路、大屏、算法、后台、价值一条不缺。
- **90 秒精编版**：只保留“开场 → 大屏 → AI 赤潮 → 红树林 → 收尾”五段，硬件与后台压成 3 个快切镜头。
- **45 秒纯大屏版**：全程只拍 `/`，用运镜（推近、平移、切换 01–05 视图）+ 数据高亮，适合展位或开场循环。

## 三、核心功能演示清单（必须拍到的镜头）

按重要性排序，剪辑时优先保证这些镜头完整：

1. **3D 海域沙盘可交互**——鼠标拖拽旋转、滚轮缩放，点位标签跟随（证明是真三维，不是贴图）。
2. **浮标点位实时数据**——点开任一浮标，右侧/底部出现该点位的水温、pH、溶解氧、浊度、叶绿素a、盐度当前值。
3. **赤潮风险分级结果**——环形图显示 Ⅰ/Ⅱ/Ⅲ/Ⅳ 级占比，AI 研判横幅给出当前风险等级与处置建议。
4. **告警弹窗自动弹出**——越限或模型预警触发时弹窗出现，展示告警编号、等级、点位、内容。
5. **后台设备台账 → 远程指令**——对某台浮标下发“设置采样间隔 / 校准 / 对时 / 重启”，界面回显执行结果。
6. **历史数据查询 → 导出 CSV**——选设备、指标、粒度、时间范围，曲线刷新后导出文件。
7. **模型指标与阈值**——赤潮模型页的准确率、宏平均 F1、ROC-AUC、Ⅲ/Ⅳ 级召回率，以及在线修改阈值并保存生效。
8. **红树林分割与变化检测**——点击“运行分割与变化检测”，出现前期/后期掩膜、新增斑块、减少斑块四张图。
9. **告警处置闭环**——在告警记录中点“处置”，填写处置说明并提交，状态由“待处置”变为“已处置”。
10. **账号与审计**——平台账号列表、新增账号表单、操作审计日志三个标签页各扫一眼。

## 五、旁白全文（可直接配音）

> 全文约 880 字，按 230 字/分钟朗读约 3 分 50 秒。若做 90 秒精编版，取段 1、5、6、9 的加粗句即可。

**段 1**
连江地处闽江口北翼，东临台湾海峡，是福建重要的海洋渔业与水产养殖基地，海域内同时分布着大面积海洋牧场与红树林湿地。**深蓝智护，是一套面向连江海域的软硬件一体化海洋生态智能监测平台。**

**段 2**
这片海域同时承受陆源排污、养殖自身污染、台风风暴潮与气候变暖的多重压力。而传统监测方式存在四个突出短板：人工乘船采样送检，单次巡检周期通常三到七天，抓不住小时级的突发异常；赤潮主要靠经验与肉眼上报，发现时往往已进入暴发期；水质数据分散在不同部门与厂商系统，口径不一；红树林则长期以季度或年度影像为主，缺少连续观测。**平台由此确定三条主线：数据从离散采样走向原位连续，风险从事后发现走向提前研判，监管从分散台账走向一张图管理。**

**段 3**
感知层是一台太阳能供电的多参数水质浮标。它集成水温、pH、溶解氧、浊度、叶绿素a与盐度六项传感器，采样间隔三百秒，可布放于海洋牧场网箱区与红树林监测点位。自上而下分为太阳能供电模块、主控与通信舱、传感器探头组和锚系配重，防护等级达到 IP68，支持海上长期无人值守运行。

**段 4**
海上点位以 LoRa 组成低功耗自组网，接入岸边边缘网关，网关再通过 4G 回传云端。链路中断期间数据写入本地队列，恢复后按时间戳顺序补传并自动去重。边缘侧同时完成超量程与突变的异常值剔除、设备心跳监测，非采样时段进入休眠以降低功耗。

**段 5**
所有数据最终汇聚到三维数字孪生大屏。画面中央是连江海域的三维沙盘，以卫星影像为底图、叠加地形高程，标注十个浮标点位、网箱分布与红树林斑块，可以用鼠标自由旋转和缩放。左侧是实时水质监测与二十四小时曲线，右侧是赤潮风险环形图与设备在线状态，顶部可切换总览、水质监测、赤潮预警、红树林和设备状态五个视图。**当指标越限或模型给出高风险判断时，告警会即时弹窗提示，底部状态栏同步汇总设备在线率与通道状态。**

**段 6**
赤潮预警是平台的核心能力。模型以二十四小时的水质时序为输入，输出未来四十八小时的风险等级：叶绿素a峰值低于五为一级低风险，五到十为二级关注，十到二十为三级中高风险，二十以上为四级高风险。特征工程共四十九维，覆盖六项指标的均值、波动、当前值、变化量与极值，并叠加水温适宜度、盐度适宜度、叶绿素a增长速率、溶解氧亏缺与季节节律等组合特征。**当前测试集上，模型准确率百分之七十六点五，ROC-AUC 零点八八七，三级和四级风险的召回率百分之六十二点三。**分级阈值可在管理后台在线修改，保存后立即生效。

**段 7**
红树林监测基于 Sentinel-2 期次影像，融合 NDVI、NDWI、MNDWI 与 CMRI 完成斑块分割和两期变化检测。目前纳入三个片区、四百六十点二公顷，面积加权健康度八十三点一，其中两个片区面积增长、一个片区略有减少。**点击运行分析，可以同时得到前期掩膜、后期掩膜以及新增和减少的斑块图，用于定位退化位置并留存期次档案。**

**段 8**
管理后台把日常运维收敛到一个入口。设备台账支持按关键字、类型、区域和状态筛选，并可远程下发采样间隔、校准、对时和重启指令；历史数据支持多设备对比、多时间粒度查询与 CSV 导出，并给出有效、可疑、无效三类数据质量统计；告警记录按级别、类型和时间检索，处置过程记录处置人与说明；账号与审计模块提供管理员、技术员、养殖户、访客四类角色权限，以及登录与配置变更的审计日志。

**段 9**
最终形成的成果包括三部分：可运行的浮标硬件原型，覆盖数据接入、聚合、告警与预测全链路的软件平台，以及赤潮四级风险预测与红树林遥感分割两套算法。**它把风险发现从事后上报，变成了提前两天的研判；把高频人工巡检，变成了原位连续观测；也为红树林的修复成效核查，留下了连续可追溯的数据依据。**深蓝智护，用数据守护连江的每一片海。

## 六、录屏执行清单

**录制前**

- 显示器分辨率设为 1920×1080、缩放 100%，关闭系统通知与输入法悬浮窗。
- 浏览器使用无痕窗口，隐藏书签栏（Ctrl+Shift+B），缩放保持 100%。
- 大屏页按 F11 全屏；后台页保留完整窗口即可，不要露出桌面。
- 登录账号 `admin`，密码 `deepblue@2026`；先切到设备管理页确认数据已加载完成。
- 若不想在成片中出现登录页，提前在浏览器登录并保留会话，录屏时直接进大屏。
- 建议先把后台“运行概览”停留 30 秒，让累计记录数稳定，避免成片中数字跳动过大。

**OBS 推荐参数**

| 项 | 建议 |
| --- | --- |
| 基础/输出分辨率 | 1920 × 1080 |
| 帧率 | 30 fps（若做慢放包装可 60 fps） |
| 编码器 | 硬件编码（NVENC / QSV）或 x264 medium |
| 码率 | 12000 – 16000 Kbps，CBR |
| 音频 | 若旁白同期录，48 kHz / 192 kbps |
| 鼠标 | 开启“高亮点击”与光标阴影，鼠标指针放大到 1.5 倍 |

**拍摄节奏建议**

- 每次点击后停 1–2 秒再动，给剪辑留出手指操作与结果呈现的分离空间。
- 三维沙盘的旋转要一次完成、匀速慢转，不要来回抖动。
- 加载类操作（查询、运行分割、重新加载模型）先录完整等待过程，后期用 2–4 倍速压缩。

## 七、剪辑流程与包装规范

**1. 粗剪（定结构）**

按 9 段顺序把素材摆上时间线，先不管转场和音乐，只保证叙事顺畅；把加载等待、误点、重复操作全部删掉。

**2. 精剪（定节奏）**

- 加载过程统一 2–4 倍速，并在右上角加“加速中”角标或时间流逝提示。
- 关键点击处做 1.1–1.25 倍局部放大（缩放关键帧），持续 1.5–2 秒后还原。
- 数据高亮：对准确率、召回率、告警条数等关键数字加圆角描边圈或下划线生长动画。
- 大屏段落用缓慢推近（推近 5%–8%），后台段落保持固定机位，避免画面同质化。

**3. 转场**

以硬切为主；模块之间用 8–12 帧的横向擦除或亮度闪白；数字孪生与算法两段之间可以用一次推近转场，制造“从海域进入模型”的感觉。全片转场种类不超过三种，避免花哨。

**4. 包装层**

- 右上角常驻模块角标：`01 项目总览` … `09 成果与价值`（可直接用海报页眉样式）。
- 左下角下三分之一标题条：出现 3 秒后淡出，字体与海报保持一致。
- 底部可加一条极窄的进度线，随段落推进填充。
- 关键结论用海报中的数据卡片以画中画方式插入 2–3 秒。

**5. 调色**

统一冷色调：色温偏冷 200–400 K，提高青色饱和度 5%–10%，压低阴影（背景更黑、数值更亮），整体对比度 +5。注意保持白字不过曝、数值可读。

**6. 字幕与字体**

- 中文字体：微软雅黑 / 思源黑体 CN，字号 36–42 px，行距 1.4。
- 样式：白字 + 深蓝半透明底（#041020，透明度 65%），底部居中，左右安全边距 120 px。
- 数字与单位用等宽字体（Consolas），与平台界面一致。

**7. 音乐与音效**

- BGM：科技感电子氛围，60–90 BPM，段落 5–6 可以略微加鼓点推进。
- 音量：旁白 -18 LUFS，BGM 在旁白段落压到 -26 LUFS，段落间隙可短暂提到 -20 LUFS。
- 音效：界面点击、视图切换、告警弹出各配一个轻量音效，音量 -24 LUFS 左右，不要盖过旁白。

**8. 导出**

主版本 H.264 / MP4，1920×1080、30 fps、CBR 14 Mbps；另存一版 8 Mbps 用于即时预览与分享。

## 九、录制注意事项

1. **数据来源要保留可见**：后台设备页会区分仿真数据与真实上行数据，剪辑时不要刻意遮挡该字段，保证数据可核查。
2. **数字要能自洽**：同一段里若多次出现设备数、观测记录数，尽量取同一次录制的结果，避免前后矛盾。
3. **告警镜头不要清空**：告警记录页保留一定数量的待处置与已处置记录，画面才有信息量。
4. **三维沙盘先等加载**：进入大屏后先等 5–6 秒让地形与贴图完全加载再开始录，避免出现空白画面。
5. **一次录制多存几条**：每个关键功能至少录两遍，剪辑时可挑选鼠标动作最干净的一条。
