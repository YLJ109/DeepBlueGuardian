# 深蓝智护 · 演示视频广播级制作规范

本页是全片唯一视觉与声音基准，任何一段素材、字幕、海报、音效都以此为准，中途不得漂移。
成片规格：**4 分 30 秒（4:00–5:00 弹性）· 1920×1080 横屏 / 1080×1920 竖屏 · 24fps · H.264 或 H.265 · AAC 48kHz 立体声**。

> 交付分辨率：**1920×1080（横屏）/ 1080×1920（竖屏）**。按要求不交付 4K，兼顾清晰度与文件体积。

---

## 1. 叙事主线

**一句话定位（写入片头字幕）**
> 深蓝智护 —— 用 AI 把连江海域的水质、赤潮、红树林与海漂垃圾，收进一块实时可研判的数字孪生大屏。

**可复述的核心价值（写入结尾字幕）**
> 一套系统，让海洋生态从"事后发现"变成"提前预警、现场闭环"。

全片一条主线，任何段落偏离主线即删。每个功能模块内部统一走这条弧线：
**背景铺垫 → 抛出问题 → 埋下解法预告 → 揭晓 → 给出参数/细节**。

## 3. 安全区（硬约束，按 1920×1080 计算）

| 安全区 | 占比 | 四边留白 | 像素留白 | 适用 |
| --- | --- | --- | --- | --- |
| 动作安全区 | 90% | 各 5% | 左右 96px / 上下 54px | 画面主体、人物、运动 |
| 标题安全区 | 80% | 各 10% | 左右 192px / 上下 108px | 所有文字、Logo、关键图形 |

- 竖屏 1080×1920 单独建安全区模板：动作区左右 54px / 上下 96px，标题区左右 108px / 上下 192px，禁止直接套用横屏参数。
- 全片所有文字、Logo、字幕必须落在标题安全区内，绝不贴边。

## 4. 字幕规范

- **禁止纯白**：主字幕用 `#DFF3FF`，深底浅字。
- 字体：思源黑体 Heavy / 微软雅黑（笔画清晰、字面充足），全片统一。
- 描边与投影：1.5px 同系深色描边（`#04101F`）+ 0.5px 浅色投影；描边优先于投影；禁止过厚描边与强发光双轮廓。
- 字号：横屏 ≈ 画面高 4%（1080p 约 43px）；竖屏 ≈ 5.5%（1080×1920 下约 106px）。
- 位置：横屏下沿往上 8%–12%（1080p 约 108px）；竖屏压到 15%（避让平台 UI）。
- 单条 ≤ 2 行，单行 ≤ 18 字（竖屏 ≤ 14 字），行高 1.4，逐句居中。
- 语速 4–6 字/秒；字幕与配音逐字对齐，音画误差 ≤ 2 帧（禁止"话说完了字才出来"）。
- **关键词高亮全片 ≤ 5 处**，强调色 + 字号 ×1.2 + 轻微弹跳，配音念到的瞬间同步触发。

建议的 5 处高亮位：
1. `0.9305` —— 海漂垃圾检出 mAP50
2. `460.2 公顷` —— 红树林监测面积
3. `100%` —— 设备在线率
4. `SHA-256 存证` —— 巡护现场不可篡改
5. `4 分 30 秒` —— 片尾价值复述前的收束点

## 5. 音频规范（广播级响度）

| 项 | 标准 |
| --- | --- |
| 整片响度（流媒体首选） | `-14 LUFS`，真实峰值 ≤ `-1 dBTP`，LRA ≤ 18 LU |
| 备选（播客） | `-16 LUFS ±1` |
| 备选（广电 EBU R128） | `-23 LUFS ±0.5` |
| 归一化方式 | two-pass 响度归一化（先测量再线性调整），禁止单程压缩 |

**分层比例**

- 配音：主持人级，全片同一人、同一音色、同一话筒距离；干声峰值 −6 ~ −3 dBFS；语速 180–200 字/分钟。
- BGM：轻快科技氛围纯音乐，比配音低 **18–20 dB**，任何时刻不盖人声。
- 音效：比配音低 **12–15 dB**，触发点与画面误差 ≤ 2 帧。
- 噪声底 ≤ −60 dBFS；转场处 20–50ms 交叉淡化防爆音。

**音效触发点清单**

| 节点 | 音效 |
| --- | --- |
| 片头 / Logo 出现 | 低频 whoosh 上升音 |
| 每个模块海报切入 | 轻量切换音 |
| 关键词高亮 | 短促 ding |
| 数据 / 图表浮现 | 数字滚动音 |
| 转场切换 | 柔和过渡音 |
| 结尾落版 | 舒缓收尾 + fade out |

---

## 6. 动效与转场

- 全部位移/缩放使用缓动（`ease-in-out` 或自然曲线），**禁止线性运动**。
- 元素入场 0.4–0.8s；UI/字幕微动效 200–400ms；关键揭示后停留 ≥1.5s，核心结论后停留 2–3s。
- 只动 `opacity` 与 `transform`，不做重特效。
- 模块间统一：**淡入淡出 + 轻微缩放**（1.04 → 1.00，0.6s），全片同一套转场语言。
- 动效词汇表（复用形成辨识度）：Fade、Slide-in、Rise、Highlight、Morph。
- 相邻镜头不使用完全相同动效；整体语法保持一致。
- 透明度分层：主体 1.0 / 语境元素 0.4 / 结构元素（网格、坐标轴）0.15。
- 背景粒子与流光透明度 ≤ 15%，不遮挡内容。

## 7. 素材类型与来源纪律

| 素材类型 | 来源 | 说明 |
| --- | --- | --- |
| 界面实拍 | 真实浏览器录制（`_video_work/rec_all_1080.js`） | 1920×1080 / 1080×1920，25fps 源，后期转 24fps |
| AI 识别画面 | 平台推理节点真实前向输出 | 检测框与置信度由 YOLO11s 海漂垃圾权重生成，**不做任何补全或伪造** |
| 监测数据 | 平台实时数据，仿真数据标注 `source=sim` | 图表数值与接口一致 |
| 红树林遥感 | Sentinel-2 期次影像统计口径 | 页面已标注数据来源 |
| 演示样本影像 | 公开海漂垃圾数据集验证集 | 画面标注"公开数据集样本，非实时画面" |
| AI 生成镜头 | 仅用于片头/背景氛围 | 产品与界面镜头一律用实拍，不用生成画面重绘 UI |

**产品/界面类镜头优先图生视频**：以已审核的真实界面截图为事实来源，生成提示词只描述运动、光线与节奏，不重述外观，避免 Logo 与文字变形。

## 8. 交付物

1. 成片：1920×1080 / 24fps / 横竖双版本，H.264 或 H.265，AAC 48kHz 立体声。
2. 可编辑工程：海报/插图/字幕/音效/BGM/特效分层，元素可独立替换。
3. 字幕文件：SRT / ASS（UTF-8，含时间码与高亮关键词标记）。
4. 音效触发点清单（节点 → 音效 → 时间码）。
5. 分镜表（镜号 / 景别 / 画面内容 / 时长 / 音效 / 备注），与工程一一对应。
6. 本规范页（色板 hex、字幕样式、转场偏好、BGM 风格与 BPM 区间）。

**BGM 风格与 BPM**：氛围电子 / 轻科技，`92–104 BPM`，4/4 拍，无强人声采样；段落切换允许 0.5s 轻微起伏，不抬升到盖过人声。
